## ✨ المميزات

### 📊 لوحة التحكم
- عرض إحصائيات القناة (المشتركون، المشاهدات، عدد الفيديوهات)
- عرض أحدث الفيديوهات
- روابط سريعة للقناة واستوديو يوتيوب

### 📤 رفع الفيديو
- رفع فيديو مع العنوان والوصف والوسوم
- اختيار التصنيف والخصوصية
- إضافة صورة مصغرة مخصصة
- جدولة النشر في وقت محدد
- تحديد ما إذا كان الفيديو موجّهًا للأطفال (مطلوب من يوتيوب)
- شريط تقدم مباشر مع إمكانية الإلغاء

### 🎬 إدارة الفيديوهات
- عرض جميع فيديوهات القناة
- تعديل العنوان والوصف والوسوم والخصوصية
- حذف الفيديوهات
- البحث والتصفية
- عرض التعليقات
- نسخ الرابط أو المعرف
- فتح في المتصفح

### 📁 قوائم التشغيل
- عرض جميع قوائم التشغيل
- إنشاء قوائم جديدة
- إضافة وإزالة فيديوهات
- حذف قوائم التشغيل

### 📦 الرفع الجماعي
- إضافة عدة فيديوهات دفعة واحدة
- رفع تلقائي واحداً تلو الآخر
- شريط تقدم لكل فيديو وللمجموعة، وحالة كل ملف أثناء الرفع
- إمكانية الإلغاء
- العناصر الناجحة تُحذف من القائمة تلقائيًا فلا يتكرر رفعها، والفاشلة تبقى لإعادة المحاولة
- تنبيه مسبق إذا كانت الدفعة أكبر من حصة الـAPI اليومية

## 🔧 التثبيت

### المتطلبات
- Python 3.10 أو أحدث (المكتبات المثبّتة تتطلب 3.10+)
- حساب Google Cloud مع تفعيل YouTube Data API v3

### الخطوات

**1. تثبيت المتطلبات**

ملفا `run.sh` و`run.bat` ينشئان بيئة افتراضية `.venv` ويثبّتان المتطلبات فيها تلقائيًا. للتثبيت اليدوي:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate   |   Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
```

**2. إعداد Google API**

1. اذهب إلى [Google Cloud Console](https://console.cloud.google.com)
2. أنشئ مشروعًا جديدًا أو استخدم مشروعًا حاليًا
3. فعّل **YouTube Data API v3**
4. أنشئ **OAuth 2.0 Client ID** من نوع Desktop
5. حمّل ملف الاعتماد، ثم اختره من داخل التطبيق: **الإعدادات ← تغيير ملف client_secret**
   (يُنسخ إلى مجلد بيانات التطبيق). أو أعد تسميته إلى `client_secret.json` وضعه في مجلد التطبيق.
   - يمكنك الاسترشاد بالقالب `client_secret.json.example` لمعرفة الشكل المطلوب
6. في **OAuth consent screen** أضف بريد حسابك في **Test users** (انظر الملاحظات المهمة أدناه)

**3. تشغيل التطبيق**

| النظام | الأمر |
|---|---|
| Windows | `run.bat` |
| Linux / Mac | `chmod +x run.sh && ./run.sh` |
| مباشرة (أي نظام) | `python main.py` |

## ⚠️ ملاحظات مهمة

### قيود Google التي تؤثر على الاستخدام (اقرأها قبل الشكوى من سلوك "غريب")

1. **الفيديوهات تُرفع "خاصة" إجباريًا من المشاريع غير المدقّقة.**
   أي مشروع Google Cloud أُنشئ بعد 28 يوليو 2020 ولم يجتز
   [تدقيق YouTube API](https://support.google.com/youtube/contact/yt_api_form)
   تُقفل كل فيديوهاته المرفوعة عبر الـAPI على **خاص**، مهما اخترت في التطبيق.
   التطبيق ينبّهك بعد الرفع إذا حصل هذا. الحل: اطلب التدقيق من Google، أو غيّر الخصوصية يدويًا من YouTube Studio.
2. **التوكن ينتهي كل 7 أيام في وضع Testing.**
   إذا كانت شاشة الموافقة (OAuth consent screen) بحالة *Testing*، يُلغى التوكن أسبوعيًا.
   التطبيق يكتشف ذلك ويفتح المتصفح لتسجيل الدخول من جديد تلقائيًا. لتفاديه: انشر التطبيق (*In production*).
3. **الحصة اليومية ≈ 6 فيديوهات.**
   الحصة الافتراضية 10,000 وحدة يوميًا، وكل رفع يكلّف 1,600 وحدة. باقي العمليات رخيصة (وحدة واحدة غالبًا).
   تتجدد الحصة عند منتصف الليل بتوقيت المحيط الهادئ، ويمكن طلب زيادتها من Google Cloud Console.

### عامة

1. عند أول تشغيل سيفتح المتصفح لتسجيل الدخول بحساب Google
2. تُحفظ الملفات في **مجلد بيانات التطبيق** (لا في مجلد التشغيل):
   - Windows: `%APPDATA%\YouTubeUpload`
   - macOS: `~/Library/Application Support/YouTubeUpload`
   - Linux: `~/.config/YouTubeUpload`

   وفيه `token.json` و`client_secret.json` (إن اخترته من الإعدادات) وسجل التشغيل `youtube_upload.log`.
   الملفات القديمة الموجودة بجانب التطبيق تُنقل إليه تلقائيًا عند أول تشغيل.
3. جدولة النشر تتطلب أن تكون القناة مؤهلة (لها سجلّ جيد). وتعديل فيديو مجدول مع إبقاء خصوصيته "خاص" يحافظ على موعد النشر
4. الصور المصغرة المخصصة تتطلب التحقق من حساب القناة، والصيغ المقبولة JPG وPNG حتى 2MB

## 🔒 الأمان

- لا يُخزَّن أي سرّ داخل الكود؛ تُقرأ الأسرار من `client_secret.json` المحلي وقت التشغيل.
- تُحفَظ بيانات اعتماد OAuth كـ JSON (لا pickle) في مجلد بيانات التطبيق، ويُنشأ الملف بصلاحيات `0600` (المالك فقط) من اللحظة الأولى على أنظمة POSIX.
- النصوص القادمة من الـAPI تُعرض كنص خام (PlainText) لا HTML.
