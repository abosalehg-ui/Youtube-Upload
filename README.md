# ▶ YouTube Upload

تطبيق شامل لإدارة قناة يوتيوب مبني بـ Python و PyQt5

---

## ✨ المميزات

### 📊 لوحة التحكم
- عرض إحصائيات القناة (المشتركون، المشاهدات، عدد الفيديوهات)
- عرض أحدث الفيديوهات
- روابط سريعة للقناة واستوديو يوتيوب

### 📤 رفع الفيديو
- رفع فيديو مع العنوان والوصف والوسوم
- اختيار التصنيف والخصوصية
- إضافة صورة مصغرة مخصصة
- جدولة النشر في وقت محدد
- شريط تقدم مباشر

### 🎬 إدارة الفيديوهات
- عرض جميع فيديوهات القناة
- تعديل العنوان والوصف والوسوم والخصوصية
- حذف الفيديوهات
- البحث والتصفية
- عرض التعليقات
- نسخ الرابط أو المعرف
- فتح في المتصفح

### 📁 قوائم التشغيل
- عرض جميع قوائم التشغيل
- إنشاء قوائم جديدة
- إضافة وإزالة فيديوهات
- حذف قوائم التشغيل

### 📦 الرفع الجماعي
- إضافة عدة فيديوهات دفعة واحدة
- رفع تلقائي واحداً تلو الآخر
- شريط تقدم لكل فيديو وللمجموعة
- إمكانية الإلغاء

## 🔧 التثبيت

### المتطلبات
- Python 3.10 أو أحدث (المكتبات المثبّتة تتطلب 3.10+)
- حساب Google Cloud مع YouTube Data API v3 مفعّل

### الخطوات

1. **تثبيت المتطلبات:**
```bash
pip install -r requirements.txt
```

2. **إعداد Google API:**
   - اذهب إلى [Google Cloud Console](https://console.cloud.google.com)
   - أنشئ مشروع جديد أو استخدم مشروع حالي
   - فعّل **YouTube Data API v3**
   - أنشئ **OAuth 2.0 Client ID** من نوع Desktop
   - حمّل ملف الاعتماد وأعد تسميته إلى `client_secret.json` وضعه في مجلد التطبيق
   - يمكنك الاسترشاد بالقالب `client_secret.json.example` لمعرفة الشكل المطلوب
   - ⚠️ لا تشارك `client_secret.json` أو ترفعه إلى GitHub (مُستثنى مسبقًا في `.gitignore`)

3. **تشغيل التطبيق:**

**Windows:**
```
run.bat
```

**Linux/Mac:**
```bash
chmod +x run.sh
./run.sh
```

**أو مباشرة:**
```bash
python main.py
```

## ⚠️ ملاحظات مهمة

1. عند أول تشغيل سيفتح المتصفح لتسجيل الدخول بحساب Google
2. بعد المصادقة الأولى تُحفظ بيانات الاعتماد في `token.json` (JSON، وليس pickle)
3. جدولة النشر تتطلب أن تكون القناة مؤهلة (لها تاريخ جيد)
4. الصور المصغرة المخصصة تتطلب التحقق من حساب القناة
5. تُكتب سجلات التشغيل في `youtube_upload.log`

## 🔒 الأمان

- لا يُخزَّن أي سرّ داخل الكود؛ تُقرأ الأسرار من `client_secret.json` المحلي وقت التشغيل.
- تُحفَظ بيانات اعتماد OAuth كـ JSON (لا pickle) بصلاحيات مقيّدة قدر الإمكان.
- إن رفعت سرّ العميل سابقًا بالخطأ، **دوّره** من Google Cloud Console.
